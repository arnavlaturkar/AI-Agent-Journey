# AI Agent Journey 🤖

A hands-on learning journey building AI agents from scratch.

## What I Built

### Week 1 — Python Foundations for Agents
- `agent_class.py` — Base Agent class with memory and inheritance
- `agent_memory.py` — Persistent JSON memory for agents
- `agent_tools.py` — Real API tool use (weather)
- `agent_brain.py` — Groq LLM integration
- `jarvis_agent.py` — Complete Jarvis agent combining everything

## Tech Stack
- Python 3.11
- Groq API (LLM)
- requests (API calls)
- python-dotenv (environment variables)

## How To Run
conda activate agent-env
python week_1/jarvis_agent.py
